# Publication boundary

MIT covers this repository's source and documentation. The clickngoal name and logo identify the original project; derivatives should identify themselves clearly and must not imply official endorsement.

The progress-days, progress-calendar, use-local-today and use-system-dark modules and applicable tests were extracted from the official 1.0.50 application on 2026-10-07. The demo and documentation were added for the community foundation. Public history starts fresh; it is not a mirror of private application history.

React, Vite, TypeScript, Vitest and dependencies retain their own licenses. package-lock.json pins dependency versions. Official APK release assets are distributions of the hosted application's client governed by its terms, not an MIT release of the full application. The public web demo is built solely from this MIT repository.
