# clickngoal — социальная сеть для целей и ежедневного прогресса

**Двигайтесь к целям, находите единомышленников и поддерживайте друг друга.**

[Открыть приложение](https://goal.clickn.dev/) · [Установка и загрузки](https://jabrailkhalil.github.io/clickngoal/ru/) · [English](README.md) · [Сообщить об ошибке](https://github.com/jabrailkhalil/clickngoal/issues)

clickngoal объединяет трекер целей, календарь привычек и социальную сеть. Отмечайте выполненные дни, записывайте результаты, делитесь прогрессом по своему выбору и следите за людьми с похожими интересами. Рабочая платформа поддерживает русский и английский языки.

## На каких устройствах работает

| Устройство | Доступно | Как установить |
| --- | --- | --- |
| iPhone / iOS | Браузер и веб-приложение на домашнем экране | [goal.clickn.dev](https://goal.clickn.dev/) в Safari → «Поделиться» → «На экран Домой» → «Открывать как веб-приложение», если есть → «Добавить». |
| iPad / iPadOS | Браузер и веб-приложение | Safari → «Поделиться» → «На экран Домой». |
| Android | Браузер, PWA и официальный APK | Меню Chrome → «Установить приложение» либо [APK](https://github.com/jabrailkhalil/clickngoal/releases/latest/download/clickngoal.apk). |
| Windows | Браузер и PWA | Chrome/Edge → «Установить приложение», когда доступно. |
| macOS | Браузер и веб-приложение | Поддерживаемый Chrome/Edge либо «Добавить в Dock» в Safari на подходящей версии macOS. |
| Linux | Браузер и PWA | Современный браузер; установка в поддерживаемом браузере на Chromium. |
| ChromeOS | Браузер и PWA | Chrome → «Установить приложение». |

На всех устройствах используется одна рабочая платформа и один аккаунт. Для входа и общих данных нужен интернет. Установка и уведомления зависят от браузера. На iPhone приложение устанавливается **через веб**, отдельного пакета App Store сейчас нет. APK — общая веб-версия в официальной Android-оболочке с системными интеграциями.

Ссылки всегда доступны на [странице загрузок](https://jabrailkhalil.github.io/clickngoal/ru/). Закрытие всплывающего предложения не мешает установить приложение позже.

## Возможности рабочей соцсети

- Личные и совместные цели, календарь выполненных дней и заметки о прогрессе.
- Счётчики активных дней, текущая серия и лучшая серия.
- Профили, лента, сообщества, комментарии и реакции.
- Видимость целей и записей, блокировки, скрытие своих записей из ленты.
- Достижения и напоминания с учётом настроек и платформы.
- Вход через Telegram или почту с паролем.
- Русский/английский, светлая/тёмная/системная тема.

## Что именно открыто

Это **открытая основа clickngoal под MIT**: настоящие отдельные модули приложения, тесты, типы данных и запускаемый локальный пример сообщества. Код можно изучать, менять и использовать в своих проектах.

Полный код рабочей платформы здесь не опубликован. Сервер входа, база пользователей, модерация, закрытые возможности и инфраструктура остаются вне репозитория. MIT относится к коду открытой основы. Рабочий сервис и официальный APK используют [условия приложения](https://goal.clickn.dev/terms.html) и [политику конфиденциальности](https://goal.clickn.dev/privacy.html).

В `src/core/` — расчёты серий, навигация календаря с клавиатуры, смена даты после полуночи, системная тема и операции локального демо. В `src/App.tsx` — пример целей, календаря, записей, ленты и комментариев. В `guides/` — архитектура, установки, ограничения и план развития.

## Запуск открытой основы

Нужны Node.js 22.12+ и npm. Python 3 — только для упаковки ZIP.

```bash
git clone https://github.com/jabrailkhalil/clickngoal.git
cd clickngoal
npm ci
npm run dev
npm run check
```

Демо хранит изменения локально. Примерные авторы и записи вымышлены. Рабочий сервер не вызывается; входа и обмена данными между людьми здесь нет. Очистка хранилища удаляет демо-данные. Это основа для изучения, а не полный сервер соцсети.

Веб-архив распакуйте, запустите внутри `python3 -m http.server 8080`, откройте `http://localhost:8080/`. Двойной клик по HTML ненадёжен для JavaScript-модулей.
