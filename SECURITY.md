# Security reports

Report suspected vulnerabilities through the [private website contact form](https://clickn.dev/en/contact/) with “clickngoal security” at the start. Do not include passwords, tokens or other people's personal data. GitHub private vulnerability reporting is also appropriate when enabled.

Include version, reproducible steps, impact and a minimal example. Do not exploit other users, run destructive scans or publish an exploit before investigation.

The public demo is local-only, not a production authorization system. Do not turn its browser storage or example user ID into real authentication.

The latest foundation release is maintained. Older packages remain for reproducibility, without a promise of ongoing fixes.
