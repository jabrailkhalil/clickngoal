clickngoal public web demo — foundation 0.1.0

This is a local example of the MIT open foundation, not the complete hosted social network.
Fictional community posts are examples. Changes stay in this browser's local storage.
There is no production API connection or authentication.

Extract this archive. In the extracted folder, run:
  python3 -m http.server 8080
Windows can also use:
  py -m http.server 8080
Open http://localhost:8080/ in your browser.
Do not double-click index.html: browsers restrict local JavaScript module loading.

Real social network and account: https://goal.clickn.dev/
Source, installation guide and issues: https://github.com/jabrailkhalil/clickngoal
All platforms and downloads: https://jabrailkhalil.github.io/clickngoal/

Очистка хранилища браузера удаляет данные этого примера.
Рабочая соцсеть с вашим аккаунтом находится отдельно на https://goal.clickn.dev/.
