# Discoverability

The repository uses a readable product title, meaningful description and relevant topics: social-network, goal-tracker, habit-tracker, pwa, community, productivity, react and typescript. English and Russian README files give users direct links to the actual application, platform instructions and packages.

The bilingual GitHub Pages project site contains server-rendered/static descriptions, unique page titles and descriptions, canonical URLs, RU/EN hreflang links, Open Graph/Twitter metadata, a product cover, SoftwareSourceCode and WebApplication JSON-LD, a sitemap and an accessible content structure. The source license is attached to SoftwareSourceCode, not falsely assigned to the whole hosted product. No fabricated ratings, review counts or popularity claims are used.

The demo has noindex to avoid indexing fictional social posts as real user content. The project pages are designed for relevant product queries, not stuffing generic keywords such as “social network” or “goals” repeatedly. The page links to the canonical hosted product and explains the open foundation's limited scope.

These steps improve clarity and search eligibility; they cannot guarantee a top ranking. Real adoption, useful content, reputable links and ongoing search diagnostics matter. [Google's SEO starter guide](https://developers.google.com/search/docs/fundamentals/seo-starter-guide).
