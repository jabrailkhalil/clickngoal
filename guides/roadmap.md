# Public roadmap

## Available in the first foundation release

- Reviewed real calendar/progress/theme modules and tests.
- A small local React community demo.
- Russian and English product/install documentation.
- Persistent official APK, public web-demo and source downloads.
- Bilingual project page, real release-download counters and contribution templates.

## Proposals for the community foundation

- Extract more small reusable accessible components from the product.
- Improve calendar keyboard/screen-reader tests and date boundary coverage.
- Document public domain contracts as they become stable.
- Add translations and clearer examples based on contributor feedback.
- Keep releases reproducible and make official binary updates easier to publish.

These are proposals, not shipped features or deadline promises. A full multi-user self-hosting edition and publication of the full production source require a separate decision. This repository currently offers an open foundation, not the complete deployed service.

The hosted product also evolves. Use Issues for user problems rather than treating this roadmap as a guarantee of specific private features.
